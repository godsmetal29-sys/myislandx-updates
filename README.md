# MyIslandX – mises à jour

Ce dépôt contient uniquement les versions compilées de MyIslandX (aucun code source).
L'application lit `latest.json` pour savoir si une nouvelle version est disponible.

## Installer MyIslandX

1. Télécharger le fichier `MyIslandX-x.y.z.exe` le plus récent de ce dépôt.
2. Le lancer. La première fois, Windows propose d'installer le **.NET Desktop Runtime 8** : accepter.

Ensuite, les mises à jour se font depuis l'application : clic droit sur l'icône MyIslandX près de l'horloge,
puis **Installer la version…**.
